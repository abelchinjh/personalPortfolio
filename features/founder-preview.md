# Founder identity preview

Branch: preview/founder-redesign. Review before production promotion.

Both public routes are pre-rendered, then hydrated. Native links preserve navigation and readable content without JavaScript. The complete 29-entry source data and original public project graphics are retained. Search enhances the archive after hydration.

The hero is an original image generated with the built-in imagegen workflow and delivered as responsive WebP derivatives. Prompt: an original monumental matte-charcoal architectural structure, precisely cut opening, deep navy interior and narrow electric-blue seam; structure on the right, left 50–55% quiet for typography; believable physical depth and grazing light; no text, logos, recognizable buildings, UI, people or stock technology imagery.

Static by default. “Play light motion” activates a CSS light sweep over the still image, not a video. Reduced-motion preference changes, hidden tabs and leaving the hero stop the effect. A cinematographic video remains a future asset; none is claimed or loaded.

The favicon is clean SVG geometry redrawn from the Pro architectural A concept, with 16/32px PNG, ICO and Apple touch exports. Manrope is self-hosted with its OFL license.

Validation: npm run build, npm test, pre-rendered archive count and original asset preservation; deployed browser QA for keyboard/skip focus, search/empty/clear states, mobile 390/320px overflow, motion and preference changes, image loading and contact links. Proposed media budgets are measured from actual compressed build assets, not a claim of real-user Core Web Vitals.
